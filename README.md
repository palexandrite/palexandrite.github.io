# Alexander L. Bulatov's website

Multilingual personal website and blog built with Hugo.

The site's layouts and styles are maintained locally in `layouts/` and `assets/css/`; Hugo does not load a separate theme or Sass compiler. The local theme began from the MIT-licensed HugoPlate starter, with its source retained in this repository.

## Development

- `npm install` installs the CSS build tools.
- `npm run dev` starts the local Hugo server.
- `npm run build` generates the production site in `public/`.

Reusable Hugo modules are listed in `config/_default/module.toml`.
